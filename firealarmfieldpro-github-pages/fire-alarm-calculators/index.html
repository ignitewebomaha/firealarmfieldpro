Choose the calculation for the task

NAC voltage drop

The fire alarm voltage drop calculator estimates loss in a two-wire DC run and compares end voltage with the device minimum you enter. Its lumped-load model differs from a segmented, device-by-device calculation.

Standby and alarm battery demand

The fire alarm battery calculator combines total standby and alarm currents with the durations you specify, then applies a capacity multiplier. Use the result as an estimate before selecting manufacturer-supported equipment.

Detection and visible notification layouts

Use the smoke detector spacing calculator for a preliminary rectangular grid. Use the strobe candela and spacing calculator to compare room mounting arrangements, output settings, and a separate straight-corridor method.
