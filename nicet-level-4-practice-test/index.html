FIVE PRACTICE QUESTIONS

A vendor proposes replacing one power supply with two independently powered listed supplies. Each meets the load calculation individually. Which unresolved issue most directly threatens a multi-strobe room layout?

  1. Whether both supplies use the same battery Ah rating
  2. Whether both supplies have the same enclosure dimensions
  3. Whether both circuits use the same conductor gauge
  4. Whether synchronization is supported across the supplies

An acceptance report verifies local alarm operation, but monitoring-station receipts are missing. The approved scope includes off-premises alarm transmission. What is the strongest closeout action?

  1. Record a deficiency and verify the required transmitted signals
  2. Accept the local results and add a monitoring contract copy
  3. Treat the panel event log as proof of signal receipt
  4. Repeat local appliance testing and append its results

A proposed change reduces speaker quantity while increasing tap wattage to preserve the same total amplifier load. What conclusion is justified from equal total watts alone?

  1. The revised layout preserves speech intelligibility
  2. The revised layout preserves sound levels throughout
  3. The revised layout requires no coverage review
  4. The revised layout preserves the summed connected load

Two technically equivalent options have a five-year service period. A costs $12,000 initially plus $1,500 at each year-end; B costs $9,000 initially plus $2,400 at each year-end. At 8%, use a five-year annuity factor of 3.993 and no residual value. Which comparison is correct?

  1. A costs about $594 less in present value
  2. B costs about $594 less in present value
  3. A costs about $4,500 less in present value
  4. B costs about $3,000 less in present value

A review finds device settings changed after the last approved load calculation. The site test passed on AC. Which response most directly closes the technical gap?

  1. Attach the AC test result to the unchanged calculation
  2. Repeat the test using the original device settings only
  3. Reconcile settings and recalculate affected power conditions
  4. Use the panel’s nominal output rating as the load allowance

LEVEL IV SAMPLE REVIEW

Evaluate the evidence behind the decision

Use this Level 4 (Level IV) practice sample to check your reasoning on the topics below. These are sample review topics, not a complete official exam outline.

Separate capacity from system behavior

Two supplies can each meet their load calculations while leaving a shared-room synchronization issue unresolved. Ask which requirement the available evidence actually verifies and which requirement still needs a supported solution.

Distinguish a local test from end-to-end verification

Local alarm operation does not by itself document receipt of off-premises signals. Compare the test record with the approved scope and close the specific gap rather than repeating an unrelated test.

Compare costs on consistent assumptions

For project alternatives, keep the scope, analysis period, timing, and discount rate consistent. Initial purchase cost and discounted recurring costs can point to different choices. State the assumptions behind the recommendation.
